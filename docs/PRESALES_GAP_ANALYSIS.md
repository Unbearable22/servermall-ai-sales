# Requirement gap analysis

Each server attribute has status CONFIRMED / UNKNOWN / NOT_SPECIFIED / NOT_APPLICABLE, optional value, source and evidence. CONFIRMED requires a value. UNKNOWN means the customer explicitly does not know; do not repeatedly ask the same question. NOT_SPECIFIED means not yet answered. NOT_APPLICABLE means genuinely irrelevant.

Ask up to two high-value questions at a time. Start with purpose, server count and workload; then CPU cores/frequency, RAM, disks, network, redundancy, budget, delivery. When client lacks technical expertise, ask about workloads and let a human engineer propose alternatives. Never silently transform AI suggestions into customer requirements.

Handoff distinguishes client-confirmed requirements, unknowns, unanswered fields and recommendations. Keep original documents as evidence.
