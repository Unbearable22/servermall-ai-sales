# Pilot plan (hypotheses, not forecasts)

Days 1–7: Validate technical responses and ownership workflow using synthetic cases.
Days 8–14: Inbound Telegram testing with approved test users; verify attachments and manager handoff.
Days 15–21: Review permissioned sources and test contact eligibility, without bulk unsolicited outreach.
Days 22–30: Analyze qualified leads, manager agreement, complaints, hallucinations and cost per lead.

Illustrative targets: >=95% correct technical answers on a curated evaluation set; zero invented stock/price promises; zero unwanted outreach; >=80% manager agreement on qualification. Commercial conversion cannot be assumed.
